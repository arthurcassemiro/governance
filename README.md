# Governance Code Builder

Working proposal of a governance code for road investment contracts in Brazil, built on the financing-channel taxonomy of the thesis (channel, tranche, contract, arrangement).

- `index.html`: the builder (one file; open in a browser). Tabs: Compose, Indicators and assessment, The code (limit and stage coverage), Contract prototypes, The references.
- Reference lists are quoted from the originals (IMF PIMA; PEFA 2016; OECD/LEGAL/0402 and 0460; World Bank PIM Reference Guide and Benchmarking Infrastructure Development; TCU iGG 2021; OC4IDS; IPEA TD 2215; PPA 2024-2027 programme 3106), with English and Portuguese names and the source of each list.
- Saved assessments and created indicators persist only on the claude.ai artifact version (https://claude.ai/artifact/N28YAV5VTYatXafeGhVbDL); on GitHub Pages the page works in read-and-compose mode without saving.

Companion pages: descriptive statistics (https://github.com/arthurcassemiro/descriptive_data) and the causal audit.
